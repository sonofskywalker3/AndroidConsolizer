## Coding gotchas learned this session (verify before reusing)
- **`Game1.lastCursorMotionWasMouse` reads True even on a controller (Android synthesized touch).** Don't gate controller-only menu/draw patches on `gamepadControls && !lastCursorMotionWasMouse` — gate on the config toggle. Memory `android-lastcursormotionwasmouse-true-on-controller`. (Directly relevant to #12 — the existing cursor code is gated on `gamepadControls`, which may be fine, but `drawMouse` is suppressed by the TOUCH control type.)
- **Android `OptionsSlider` thumb position = `_percent`, recomputed only in the `value` setter** from `sliderMinValue/sliderMaxValue`. If you change min/max after construction, re-trigger the `value` setter or the thumb renders against the stale (default 0-100) range until first input.
- **`Utility.To4` is Android-only** (absent on the PC reference DLL) — inline it if needed.
- **Patching `DialogueBox.draw` is safe on Android**; only `GeodeMenu.releaseLeftClick` is the SIGSEGV landmine.
